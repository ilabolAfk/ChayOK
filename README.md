# ChayOK

Автономный голосовой помощник с сенсорным экраном на Raspberry Pi 4B.

Гибридная архитектура: локальная обработка звука на Raspberry Pi + мощная LLM на ПК по сети.
Помощник слышит слово пробуждения, понимает русскую речь и отвечает голосом и на экране.

## Возможности

- **Wake word** — пробуждение по словам «чайок / чаёк / чаек / чай ок».
- **Голосовой диалог** — распознавание речи локально, ответ LLM потоком, озвучка по предложениям.
- **Интерфейс на сенсорном экране** — Pygame 800×480, без рамки окна, с кнопками.
- **Погода** — текущая и прогноз на 3 или 7 дней (OpenWeatherMap).
- **Радио** — интернет-радио с окном выбора: ручной ввод частоты/названия и кнопки станций.
- **Анекдоты** — случайный чистый анекдот из локального файла.
- **Будильник** — настройка времени и уровня жёсткости, срабатывание с мелодией.
- **Редактор команд** — свои команды-триггеры через графическое окно.
- **Мониторинг батареи** — заряд через датчик INA219 по I2C (при наличии smbus2).
- **Выключение устройства** — кнопкой и голосом.

## Как это работает

| Где | Роль |
| --- | ---- |
| Raspberry Pi | Захват и распознавание речи (Vosk), синтез голоса (Piper), интерфейс (Pygame), локальная LLM-fallback |
| ПК в домашней сети | Основная генерация ответа — Qwen2.5 7B через Ollama (`/api/chat`, стриминг) |

При недоступности ПК помощник автоматически переключается на локальную модель Qwen2.5 0.5B на самом Pi.

## Требования и железо

Рекомендуемая конфигурация:

- Raspberry Pi 4B (4 GB RAM)
- Сенсорный экран 5" IPS 800×480, MIPI-DSI
- USB-микрофон, USB-колонка (или 3.5 мм)
- UPS HAT + аккумуляторы 2×18650
- Датчик тока/напряжения INA219 (I2C, адрес `0x42`) — опционально
- Радиаторы и вентилятор

Программные зависимости:

- Python 3.9+
- Vosk (модель `vosk-model-small-ru-0.22`)
- Piper TTS (голос `ru_RU-ruslan-medium`)
- Ollama на ПК (модель `qwen2.5:7b-instruct`) и опционально на Pi (`qwen2.5:0.5b-instruct`)
- mpg123 (для прослушивания радио)
- PipeWire (`pw-play`), ALSA (`arecord`, `aplay`)
- Pygame, Tkinter, smbus2 (опционально)

## Установка

### 1. Подготовка Raspberry Pi

```bash
sudo raspi-config
# Interface Options → I2C → Yes
```

### 2. Код и окружение

```bash
git clone <repo> && cd ChayOK
python3 -m venv --system-site-packages venv
source venv/bin/activate
pip install vosk pyaudio pygame requests smbus2
```

### 3. Модель Vosk (распознавание речи)

```bash
wget https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip
unzip vosk-model-small-ru-0.22.zip && mv vosk-model-small-ru-0.22 vosk-model
```

### 4. Piper TTS (синтез голоса)

```bash
cd /home/pi
wget https://github.com/rhasspy/piper/releases/download/2023.11.14-2/piper_linux_aarch64.tar.gz
tar -xf piper_linux_aarch64.tar.gz && mv piper_linux_aarch64 piper && cd piper
wget https://huggingface.co/rhasspy/piper-voices/resolve/main/ru/ru_RU/ruslan/medium/ru_RU-ruslan-medium.onnx
wget https://huggingface.co/rhasspy/piper-voices/resolve/main/ru/ru_RU/ruslan/medium/ru_RU-ruslan-medium.onnx.json
```

### 5. Радио

```bash
sudo apt install mpg123
```

### 6. Выключение без пароля (для кнопки «Выкл»)

```bash
sudo visudo
# Добавить строку:
pi ALL=(ALL) NOPASSWD: /sbin/shutdown
```

## Настройка

Все ключевые параметры собраны в начале файла `main.py`:

| Параметр | По умолчанию | Описание |
| -------- | ------------ | -------- |
| `WAKE_WORDS` | `["чайок", "чаек", "чаёк", "чай ок"]` | Слова пробуждения |
| `COMMAND_SILENCE` | `2.5` | Секунд тишины до отправки команды |
| `BASE_DIR` | `/home/pi` | Корневой каталог проекта |
| `SERVER_OLLAMA_URL` | `http://192.168.1.108:11434/api/chat` | Адрес LLM-сервера на ПК |
| `SERVER_OLLAMA_MODEL` | `qwen2.5:7b-instruct` | Основная модель |
| `LOCAL_OLLAMA_URL` | `http://localhost:11434/api/chat` | Локальный Ollama на Pi |
| `LOCAL_OLLAMA_MODEL` | `qwen2.5:0.5b-instruct` | Модель-fallback |
| `WEATHER_API_KEY` | `ТВОЙ_КЛЮЧ_СЮДА` | Ключ OpenWeatherMap |
| `CITY` | `Moscow` | Город для погоды |
| `MIC_CARD` / `MIC_DEVICE` | `1` / `0` | Аудио-карта микрофона |
| `SPK_CARD` / `SPK_DEVICE` | `1` / `0` | Аудио-карта колонки |

Чтобы узнать номера карт, выполните:

```bash
arecord -l   # список микрофонов
aplay -l     # список колонок
```

## Запуск

```bash
./start_all.sh
```

Скрипт:

1. Активирует виртуальное окружение `venv`.
2. Проверяет доступность сервера Ollama на ПК (при отсутствии — используется локальная модель).
3. Запускает `main.py`.

Для автозапуска при загрузке добавьте в crontab:

```bash
crontab -e
@reboot sleep 30 && cd /home/pi/ChayOK && ./start_all.sh >> log.txt 2>&1
```

## Команды

Помощник понимает голос и кнопки на экране:

- **Погода** — `погода`, `погода в Москве`.
- **Прогноз** — `прогноз`, `прогноз на неделю`, `прогноз на 7 дней`.
- **Будильник** — открывает редактор будильника (кнопка), либо голосовая обработка через модуль `alarm`.
- **Радио** — `включи радио радиостанция`, `радио`, `выключи радио`, `стоп радио`.
- **Анекдот** — `расскажи анекдот`, `шутку`.
- **Редактор** — `редактор`, `скрипт` — окно редактирования своих команд.
- **Выключить** — кнопка «Выкл» (отключает устройство).

Любая нераспознанная команда передаётся в LLM как обычный запрос.

## Конфигурационные файлы

### `custom_commands.json`

Свои команды-триггеры. Если команда встречается в запросе, помощник отвечает «Выполнено: …».

```json
{
  "commands": ["включи свет", "выключи свет"]
}
```

### `alarm.json`

```json
{
  "alarms": [
    {"time": "07:30", "melody": "melody1.mp3"},
    {"time": "09:00", "melody": "melody2.mp3"}
  ]
}
```

### `radio.json`

Список станций в формате «ключ» → «URL аудиопотока». Ключ — название или частота.

```json
{
  "радио 7": "https://radio7.icecast.i-tv.ru/radio7",
  "монте-карло": "https://icecast-monte.mediacdn.ru/monte"
}
```

### `jokes.txt`

Анекдоты. Каждый анекдот — блок из одной или нескольких строк, блоки разделяются пустой строкой.

```
Первый анекдот.
Со второй строкой.

Второй анекдот.
```

## Модули

### `main.py`

Главный модуль. Отвечает за:

- Настройки и константы.
- Цветовую палитру и шрифты интерфейса.
- Рисование (скруглённые прямоугольники, линии со свечением).
- Окна: редактор команд, редактор будильника, окно радио.
- Погоду (текущую и прогноз) через OpenWeatherMap.
- Озвучку Piper (по предложениям, с защитой от наложения через `audio_lock`).
- Потоковый запрос к LLM с fallback на локальную модель.
- Разбор команд (`process_command`).
- Голосовой движок `VoiceEngine` (Vosk + arecord).
- Класс интерфейса `ChayOKUI` и главный цикл `main`.

### `alarm.py`

Будильник. Функции:

- `load_alarm()` / `save_alarm()` — чтение и запись настроек (доступны из `main.py`).
- `process_alarm_command()` — обработка голосовой команды будильника.
- `alarm_checker(callback)` — фоновый цикл проверки расписания; вызывает `callback(level, label)` при срабатывании.
- `stop_alarm()` — остановка текущего будильника.

### `addition.py`

Дополнительные функции:

- `get_joke()` — случайный анекдот из `jokes.txt`.
- `play_radio(station)` — включение станции через `mpg123` (по ключу или частичному совпадению).
- `stop_radio()` — остановка радио.
- `list_stations()` — список доступных станций из `radio.json`.
- `process_addition_command(command)` — разбор команд анекдотов и радио.

### `start_all.sh`

Скрипт запуска: активация окружения, проверка Ollama, запуск `main.py`.

## Устранение неполадок

| Проблема | Решение |
| -------- | ------- |
| LLM 404 (сервер) | `ollama pull qwen2.5:7b-instruct` на ПК |
| Нет звука от LLM | Прописать корректный IP ПК в `SERVER_OLLAMA_URL` |
| Mic not found | Проверить `arecord -l`, обновить `MIC_CARD` / `MIC_DEVICE` |
| Нет вывода звука | Использовать `pw-play`, проверить `SPK_CARD` / `SPK_DEVICE` |
| Радио не играет | Установить с `mpg123`, проверить URL в `radio.json` |
| «Батарея --%» | Проверить `i2cdetect -y 1` (адрес `0x42`), установить `smbus2` |
| Будильник пропускает минуту | Увеличить `time.sleep` в `alarm_checker` |
| Нет анекдотов | Заполнить `jokes.txt` (блоки через пустую строку) |
