# ЧайОК

Голосовой помощник на Raspberry Pi 4: распознавание речи, ответы локальной модели,
озвучка, радио, будильник, таймер и уведомления на почту.

## Что умеет

- **Голос**: Vosk (русская модель, 16 кГц), слово-активатор «ЧайОК», окно продолжения
  диалога 5 секунд без активатора.
- **Ответы**: локальная модель через `llama-server` (Bonsai, GGUF) с резервом на
  Ollama по сети. Контекст — последние 4 реплики.
- **Озвучка**: Piper, голос `ru_RU-ruslan-medium`, вывод через PipeWire (`pw-play`)
  с откатом на ALSA.
- **Радио**: 25 станций из `radio.json`, выбор по названию и алиасам, переключение
  и остановка голосом, приглушение на время ответа.
- **Будильник**: уровни «мягкий/средний/жёсткий», своя мелодия, повтор каждые 5 минут.
- **Таймер**: «таймер на 5 минут», звенит до команды «стоп».
- **Погода**: текущая и прогноз на неделю (Open-Meteo, без ключа).
- **Экран**: часы, дата, будильник, громкость, станция, заряд батареи, кнопки.
- **Почта**: старт/остановка приложения, падение и восстановление LLM-сервера,
  необработанные исключения. Сторож сам поднимает `llama-server`.

## Состав

| Файл | Назначение |
|---|---|
| `main.py` | экран, распознавание, команды, LLM, озвучка |
| `radio.py` | станции, поток, громкость через `pactl` |
| `timer.py` | таймер со звонком до остановки |
| `alarm.py` | будильник и мелодии |
| `addition.py` | дополнительные команды |
| `volume.py` | общий уровень громкости (`volume.json`) |
| `audio_guard.py` | флаг «устройство сейчас говорит» |
| `notifier.py` | письма через SMTP |
| `watchdog.py` | слежение за `llama-server` |
| `start_all.sh` | запуск приложения и модели |
| `restart_llm.sh` | подъём `llama-server` |
| `chayok.service`, `install_service.sh` | автозапуск через systemd |

## Установка

```bash
sudo apt install -y python3-venv libsndfile1 ffmpeg pulseaudio-utils alsa-utils
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
```

Модели и бинарники в репозиторий не входят, их нужно положить рядом:

- `vosk-model/` — русская модель Vosk;
- `piper/` — бинарник Piper и `ru_RU-ruslan-medium.onnx`;
- `sounds/melody1..4.mp3` — мелодии будильника и таймера;
- `../llama.cpp/models/*.gguf` — модель для `llama-server`.

## Секреты

В репозитории их нет. Нужно создать локально:

- `notify.json` — по образцу `notify.example.json`: логин, **пароль приложения**
  Google и адрес получателя. Файл держите с правами `600`.

Погода работает без ключа (Open-Meteo), поэтому `api.txt` больше не нужен.

```bash
cp notify.example.json notify.json
chmod 600 notify.json
```

## Запуск

```bash
bash start_all.sh          # вручную
sudo ./install_service.sh  # автозапуск через systemd
```

Проверка почты: `venv/bin/python notifier.py`.

## Голосовые команды

«ЧайОК, какая погода», «прогноз на неделю», «включи радио монте карло»,
«следующая станция», «громче», «тише», «на всю», «будильник на 7 30 мягкий»,
«таймер на 5 минут», «стоп», «что играет», «забудь всё».
