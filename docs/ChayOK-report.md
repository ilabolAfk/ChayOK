# ЧайОК — технический отчёт

Дата: 23 ноября 2026. Устройство: Raspberry Pi 4B, 4 ГБ, панель DSI 800×480.
Состояние: рабочее, служба `chayok.service` активна, релиз `v1.6.1`, ветка `main` @ `0f8d60c`.

---

## 1. Что это такое

Голосовой помощник в корпусе с экраном и батареей. Слушает микрофон, распознаёт речь
офлайн (Vosk), отвечает коротким текстом и синтезированной речью (Piper), умеет радио,
таймер, будильник, погоду, считает арифметику и показывает заставку-часы.

Модель работает локально на самом Pi: Bonsai-4B в 1-битном кванте через llama.cpp.
Интернет нужен только для погоды и радио.

## 2. Железо и окружение

| Компонент | Что стоит | Пояснение |
|---|---|---|
| Плата | Raspberry Pi 4B, 4 ГБ | Не 8 ГБ: память делится между моделью, Vosk и системой |
| Экран | DSI-панель 800×480, подсветка `/sys/class/backlight/10-0045` | Яркость меняется без root: пользователь `pi` в группе `video` |
| Микрофон | USB PnP Sound Device (card 1) | Пишет через `arecord` напрямую в ALSA, поэтому снаружи записать нельзя |
| Звук | PulseAudio, вывод через `pw-play` | Радио играет `ffplay`, потому что `pw-play` не умеет сетевые URL |
| Питание | UPS HAT c тумблером, 2S батарея | Заряд оценивается по напряжению, точный ток не измеряется |
| ОС | Debian 13 trixie, ядро 6.18 | Python 3.13 в venv проекта |
| Модель | `Bonsai-4B-Q1_0.gguf`, 546 МБ | Qwen3-4B, сжатый в 1-битный квант |
| Распознавание | `vosk-model-ru-0.22` | Полная модель, ~1 ГБ |
| Синтез | Piper `ru_RU-ruslan-medium` | 60 МБ, работает быстрее реального времени |

## 4. Путь голосовой команды

| Этап | Что происходит | Время (замер) | Пояснение |
|---|---|---|---|
| Ожидание | Vosk слушает поток 16 кГц | постоянно | Кадр 4000 байт ≈ 125 мс, тишина отбрасывается |
| Слово-активатор | Ищем «чайок» без пробелов и с вариантами | < 1 мс | Vosk слышит «чи йоко», поэтому сравнение нечёткое |
| Запись команды | Копим текст до паузы 2,5 с | по речи | Пауза настраивается `command_silence` |
| Маршрутизация | `process_command` перебирает обработчики | 0,01–0,11 мс | Кто первый совпал, тот и отвечает |
| Модель (если не совпало) | Llama.cpp стримит токены | TTFB 0,7 с, 1,5 ток/с | Первый запрос после смены промпта — 8–42 с |
| Обрезка | После 2 предложений поток рвётся | — | Лимит `llm.max_sentences` |
| Синтез | Piper превращает фразу в WAV | 4,4 с на 6,9 с речи | RTF 0,63: синтез быстрее воспроизведения |
| Воспроизведение | `pw-play`, радио приглушается | по длине фразы | Очередь фраз не перемешивается |

## 6. Замеры модели

Замер на самом Pi, промпт как в приложении, лимит 45 токенов.

| Метрика | Значение | Пояснение |
|---|---|---|
| Время до первого токена (кэш горячий) | 0,6–0,7 с | Префикс уже обработан, идёт только генерация |
| Время до первого токена (кэш пуст) | 8–42 с | После смены системного промпта или старта |
| Скорость генерации | 1,5 ток/с | Потолок для 4B в 1 бите на Cortex-A72 |
| Ответ в 20 токенов | ≈ 13 с | Короткая реплика |
| Ответ в 45 токенов | ≈ 30 с | Предел текущих настроек |
| Первый ответ после старта | 5,3 с прогрева вместо 8–42 с | Добавлен прогрев промпта при запуске |

Экстраполяция: чтобы ответ приходил за 10 секунд, нужно либо ≤ 15 токенов, либо модель
вдвое быстрее (Qwen2.5-1.5B).

## 10. Принятые решения и почему

| Решение | Причина | Пояснение |
|---|---|---|
| Калькулятор в обход модели | 4B в 1 бите ошибается в арифметике | Модель дала «8» на `2+2*2`, приложение — «6» |
| Быстрые ответы в `quick.py` | Модель тратит 30 с на то, что известно | Время, дата, громкость считаются мгновенно |
| Обрезка по предложениям | Модель игнорирует просьбу «кратко» | Лимит токенов не спасал: ответ был одной длинной фразой |
| Прогрев промпта при старте | Первый запрос ждал до 42 с | Прогрев занимает 5,3 с в фоне |
| Нечёткое слово-активатор | Vosk слышит «чи йоко» | Сравнение без пробелов и с вариантами |
| Автоусиление микрофона | С расстояния речь тише -40 dBFS | После AGC распознавание заработало |
| Притухание вместо гашения | Нужно видеть часы | Остаётся читаемым при 25/255 |
| Piper вместо Silero | Разница на слух незначительна | Silero добавила бы 600 МБ RAM |
| Отказ от XTTS и подобных | Не тянет Pi 4 | Остаются вариантом «студийный голос с ПК» |

## 11. Известные ограничения

| Ограничение | Причина | Что можно сделать |
|---|---|---|
| Ответ идёт ~30 с | 1,5 ток/с | Сменить модель на Qwen2.5-1.5B, урезать ответ |
| Первый ответ после смены промпта медленный | Кэш префикса пуст | Прогрев при старте уже есть; промпт не менять без нужды |
| `custom_commands.json` не работает | Выполняется как shell-команда | Привязать к GPIO или сменить формат |
| Статусы загрузки не видны | Plymouth завершается раньше службы | Нужен root-юнит до `plymouth-quit` |
| Точный ток батареи неизвестен | Шунт не откалиброван | Калибровка по напряжению |
| Модель иногда уходит в другой язык | Деградация 1-битного кванта | Смена модели |
| Микрофон занят приложением | Прямой доступ к ALSA | Запись только через сам ЧайОК |
